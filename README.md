# Signature Verification

This project provides a starter structure for signature verification experiments on CEDAR, BHSig260 Hindi, and BHSig260 Bengali datasets.

## Structure

- data/raw/: original datasets
- data/processed/: preprocessing outputs
- data/splits/: deterministic train/val/test splits
- src/sigver/: installable package
- configs/: experiment YAML files
- scripts/: entry-point scripts
- tests/: regression tests
